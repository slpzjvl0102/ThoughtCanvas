ThoughtCanvas 업데이트 예정

0.6.9 반영 완료 (2026-11-17) — 아래 1~3

1. Board 목록 정리
   - 이 기기에 있는 Board는 Drive(☁) 줄을 숨김 (현재: 저장본 해시 ID와 비교해 항상 중복 표시되는 버그)
   - 다른 기기에 더 새로운 변경이 있을 때만 해당 Board 줄에 '다른 기기 변경 있음' 표시
   - 이 기기 자신의 백업은 목록에 표시하지 않음

2. Drive 백업 폴더를 Board ID 기준으로 통일
   - Board ID는 이름 변경 시에도 유지 (기기 간 연결·과거 원본·동기화 기록이 ID 기준)
   - 백업 폴더를 ID로 찾아 이름이 바뀌어도 같은 폴더에 저장
   - 이미 갈라진 옛 폴더(예: 새로운 생각_7be245… / 에픽세븐BM_7be245…)는 다음 백업 때 하나로 합침

3. Drive 백업 버전 자동 정리
   - Board·기기별로 최근 5개 버전 폴더만 보관, 백업 직후 오래된 폴더 삭제
   - 업로드 중(snapshot.pending)이거나 미완성인 폴더는 건드리지 않음

결정 완료
